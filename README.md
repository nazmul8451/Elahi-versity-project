# RigCraft - Custom PC Builder & Hardware Store Mobile App

A modern, high-performance Flutter mobile application for PC building, custom hardware configuration, prebuilt PC purchases, and order tracking.

---

## ✨ Features

- **🚀 Animated Splash Screen**: Glowing cyber branding with dynamic loading status.
- **🏠 Home & Storefront**: 
  - Promotional hero banners with high-res hardware imagery.
  - Category filters (Gaming PCs, Workstations, CPUs, GPUs, Motherboards, RAM, Storage).
  - Prebuilt PCs showcase with spec chips (CPU, GPU, RAM), pricing, and discount badges.
  - Trending components with one-tap "Add to Build" capability.
- **🔍 Pre-Built PC Details**: 
  - In-depth hardware breakdown and performance stats.
  - **"Customize in Builder"**: Instantly loads the configuration into the custom builder.
- **🛠️ Custom PC Builder**:
  - Live Total Price calculation.
  - Estimated Wattage consumption meter.
  - Real-time Hardware Compatibility Checker (Socket matching, DDR generation, PSU wattage).
  - Step-by-step slot selector for CPU, Motherboard, GPU, RAM, Storage, PSU, Cooler, and Case.
  - Build Summary & Checkout sheet with optional OS installation & stress test services.
- **📦 Order Tracking**:
  - Active & Completed order views.
  - Multi-stage assembly and delivery progress timeline.
  - Itemized receipt breakdown and support desk shortcuts.
- **👤 Profile & Saved Builds**:
  - User stats, saved custom rigs gallery with one-click reload into builder.
  - Warranty hub, address management, and settings.

---

## 🛠️ Tech Stack

- **Flutter**: 3.44+
- **Dart**: 3.12+
- **UI Architecture**: Material 3 Design System with Custom Cyber Tech Theme
- **State Management**: Reactive ChangeNotifiers & ListenableBuilder

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nazmul8451/Elahi-versity-project.git
   ```

2. **Get dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```
